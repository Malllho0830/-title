2. 국내 생산물 최종수요 증가 시뮬레이션

수입 완제품 구매를 제외한 국내 생산물 최종수요 증가를 입력하세요. 여러 산업의 증가액은 합산됩니다. 선택한 분류의 부문 단위로 계산합니다.

1,000백만원 = 10억원. 이번 버전은 양의 수요 증가만 지원합니다.

    3. 산업 연쇄효과 분석

    생산유발계수표(레온티에프 역행렬)로 각 산업의 영향력계수와 감응도계수를 계산합니다. 분류를 바꾸면 해당 분류 기준으로 다시 계산됩니다.

    자료를 불러온 후 표시됩니다.

    산업 연쇄효과 — 무단위 지수, 전 산업 평균 = 1
    코드산업영향력계수감응도계수유형

    영향력계수 = 해당 산업 열합 ÷ 전 산업 열합 평균. 이 산업의 최종수요가 늘 때 전체 산업의 생산을 얼마나 끌어올리는지(후방연쇄)를 나타냅니다. 감응도계수 = 해당 산업 행합 ÷ 전 산업 행합 평균. 모든 산업의 최종수요가 1단위씩 늘 때 이 산업이 받는 영향(전방연쇄)을 나타냅니다. 1보다 크면 평균 이상입니다. 영향력계수는 한국은행 원표(생산유발계수 시트 9801행)와 일치함을 확인했습니다.

    4. 최종수요 항목별 유발 분해

    원표의 "최종수요 항목별 유발액" 시트를 이용해, 생산·수입·부가가치가 소비, 투자, 수출 중 무엇 때문에 유발되었는지 나누어 봅니다. 소비는 민간소비와 정부소비, 투자는 민간·정부 고정자본형성과 재고증감, 귀중품 순취득을 합한 것입니다.

    자료를 불러온 후 표시됩니다.

    생산유발액 구성 (소비·투자·수출)

    산업별 분해

    산업을 선택하세요.
    최종수요 항목생산유발액구성비(%)수입유발액부가가치유발액

    구성비는 해당 행의 생산유발액을 최종수요계로 나눈 값입니다. 재고증감은 음수가 될 수 있고, 국내 생산물 수요만 대상이라 수입 완제품 구매는 포함되지 않습니다. 금액 단위는 백만원이며, 각 연도의 당해 연도 가격(명목) 기준입니다.

    5. 연도 간 비교

    위 2번 시뮬레이션에서 추가한 시나리오(현재 선택한 분류 기준)를 2022·2023·2024년 산업연관표로 각각 계산해 나란히 비교합니다. 연도마다 파일을 불러와 계산하므로 1~2분 걸릴 수 있습니다.

    시뮬레이션에서 시나리오를 추가한 뒤 비교하세요.

    산업별 비교

    수요 증가액은 모든 연도에 같은 금액(백만원)을 넣었고, 결과 차이는 연도별 산업구조(투입계수)의 차이에서 나옵니다. 연도별 가격 수준 차이는 반영하지 않았습니다(명목). 계수 = 유발액 ÷ 수요 증가액.
