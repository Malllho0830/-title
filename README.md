# 연도별 산업연관표분석

GitHub Pages에서 동작하는 산업연관표 분석 웹앱입니다. 브라우저에서 Pyodide(WebAssembly Python)가 엑셀을 읽고 계산하므로 별도 서버가 필요 없습니다.

## 자료
- 출처: 한국은행 경제통계시스템(ECOS) 산업연관표 > 연도별 연장표 > 투입산출표 > 생산자가격 (2023년, 2024년)
- 분류: 통합대분류(33개), 통합중분류(83개), 통합소분류(165개), 기본부문(380개)
- 연장표는 2020년 실측표를 기준으로 간접 추계한 표입니다.
- 파일: `data/io-{연도}-{large|mid|small|basic}.xlsx` (예: `io-2024-large.xlsx`). 연도를 추가하려면 같은 이름 규칙으로 파일을 올리고 `app.js`의 `YEARS`에 연도를 추가합니다.
- 각 파일은 12개 시트(총·수입·국산 거래표, 총·수입·국산 투입계수, 생산·수입·부가가치 유발계수, 최종수요 항목별 유발액 3종)로 구성됩니다.

## 단위
- 거래표·유발액: **백만원** (1,000백만원 = 10억원)
- 투입계수·유발계수: 무단위 (금액 1단위당 유발되는 금액)
- 영향력계수·감응도계수: 무단위 지수 (전 산업 평균 = 1)

## 사용법
1. 사이트 상단에서 연도와 분류(대분류/중분류/소분류/기본부문)를 고르고 **불러오기**를 누릅니다. 처음에는 Pyodide를 내려받느라 수십 초 걸릴 수 있습니다.
2. **시뮬레이션** 탭: 산업과 최종수요 증가액(백만원)을 추가한 뒤 **파급효과 계산**을 누르면 같은 화면에 생산·수입·부가가치 유발액이 나옵니다. 결과는 CSV로 내려받을 수 있습니다.
3. **연쇄효과** 탭: 산업별 영향력계수·감응도계수와 유형을 확인합니다.
4. **원자료 탐색** 탭: 시트와 행을 고르고 행·열 이름으로 검색해 원자료를 확인합니다.

## 분석 방법
- 국산 투입계수 `Ad`, 수입 투입계수 `Am`, 부가가치 계수 `v`(총투입계수표 9690행)를 사용합니다.
- 생산유발계수 `L = (I − Ad)^-1`, 수입유발계수 `M = Am·L`, 부가가치유발계수 `V = diag(v)·L`
- 수요충격 `f`에 대해 생산유발액 `x = L·f`, 수입유발액 `m = M·f`, 부가가치유발액 `va = V·f`
- 불러올 때마다 위 관계가 원표의 계수와 맞는지 검증합니다(허용 오차 1e-8). 4개 분류 모두 통과했습니다.
- 영향력계수(후방) = 열합 ÷ 열합 평균, 감응도계수(전방) = 행합 ÷ 행합 평균
- 유형: 두 계수 모두 1 초과 = 전·후방 모두 큼, 영향력만 초과 = 후방연쇄 큼, 감응도만 초과 = 전방연쇄 큼, 둘 다 이하 = 연쇄 작음

## 한계
- 국내 생산물 최종수요의 양의 증가만 지원합니다.
- 취업·고용유발효과는 아직 포함하지 않습니다(고용표 필요).
- 연장표는 추계 자료이므로 실측표와 차이가 있을 수 있습니다.

## 파일 구성
`index.html`(화면), `style.css`(디자인), `app.js`(동작), `worker.js`(Python 실행), `model.py`(엑셀 읽기·검증·계산), `.nojekyll`, `data/`(엑셀)
